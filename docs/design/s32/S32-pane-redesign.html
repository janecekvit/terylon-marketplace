Terylon Pane — a redesign on what Claude Desktop 2.1.304 can do (S32 #370, v3)

Builds on S15 v2 (the band and the pane, 1.1.2 from PR 219). The content and the rules do not change: the pane shows, asks, answers and sends, and never approves; merge and the other gates stay a link into the console; the band is one line and the status line tells the health. What changes is the drawing: since 2.1.295–2.1.299 a mod in Desktop can set font size and weight, tabular figures, named spacing, a row as one button with a chip, Svg, Select, Code and a multi-line field.

The pane's texts are in English, as in 1.1.x (from hooks/copy.ts); the captions around the boards are design notes. Pane width 520 px, as in S15 v2; narrow dock 360 px. Every board has numbered pins: which API element draws what. In orange = present in the declarations, but phase 2 must first verify it on Desktop 2.1.304; it has a fallback, which is the 1.1.2 drawing.

v3 · PROPOSED · Svg in Desktop's light theme — the colours inside an Svg do not read the theme

Svg is a document with no theme input: its colours are fixed. Hence: a transparent background, medium-saturated colours legible on both white and dark, grey as transparency (not a fixed dark), no word inside the Svg — every word in Text, which follows the theme. Shown here: the same Svg as in the dark pane; nothing else changes.
