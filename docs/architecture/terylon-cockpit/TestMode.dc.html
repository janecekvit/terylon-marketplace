Test mode: nothing was merged. A real merge is made in the console, on the commit with the green verdict.
What it does
Opened by /terylon-cockpit test, closed by /terylon-cockpit test off.
Answers every call of the pane from made-up data: one goal per road stage, a stuck story, a question, a plan, notices and memory.
The acts move that data in memory: Approve, Accept, Answer, Mark handled, Confirm, Drop, New goal.
Says Test mode in the head, the band, the status line and the pane's title.
What it does not
It sends nothing to Terylon, and posts nothing into the chat.
It writes nothing to the store the sessions share, and takes no lease, so every other session goes on as it was.
It covers the pane alone: Claude's own Terylon tools in that chat still reach the real Terylon.
It leaves when the session does: test off returns to live data, as it was.
